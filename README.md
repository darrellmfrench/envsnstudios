# ENVSN Studios Plugins

Custom WordPress plugins built and maintained by ENVSN Studios. Each plugin
lives in its own folder under `wp-plugins/` and can update itself on client
sites from this repo's GitHub Releases.

## Plugins

- **wp-plugins/bac-blocks** — Custom Elementor widgets for Branded Apparel Club.
